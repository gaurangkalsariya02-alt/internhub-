# InternHub - React Student Internship Management System

## What is this?
A beginner-friendly responsive React project for a BCA student internship portfolio.

### Included
- React + Vite
- Responsive design for mobile, tablet and laptop
- Home page
- Internship listing + search
- Student registration UI
- Login demo
- Student dashboard
- Apply button and application tracking
- Clean portfolio-ready UI

## Requirements
Install Node.js (LTS) on Windows.

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted `Student-Internship-React` folder in VS Code.
3. Open Terminal in VS Code.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost address shown in the terminal (usually http://localhost:5173).

## Important
This version uses frontend demo data only. Login, registration and applications are stored only in the current browser session.
